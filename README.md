# 🏋️ WeFit – Android Fitness App

WeFit is an Android fitness application that helps users maintain a healthy lifestyle through short workout videos, nutritious meal recipes, and daily step tracking. The app is designed for users who want quick, effective workouts and simple health tracking in one place.

---

## 📱 Features

### 🎥 Workout Videos
- Workout videos with durations **under 30 minutes**
- Suitable for beginners and intermediate users
- Includes cardio, strength, flexibility, and full-body workouts

### 🥗 Healthy Meal Recipes
- Collection of healthy and balanced meal recipes
- Displays ingredients and step-by-step preparation instructions
- Helps users make better food choices

### 🚶 Daily Step Counter
- Tracks daily steps using the phone’s built-in sensors
- Real-time step count display
- Encourages daily physical activity

---

## 🛠️ Technologies Used

- **Platform:** Android
- **Programming Languages:** Kotlin & Java
- **UI Design:** XML, Material Design
- **Build System:** Gradle
- **Sensors:** Android Step Counter Sensor
